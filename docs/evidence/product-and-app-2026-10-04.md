## 页面与边界

| 入口 | 用途 |
|---|---|
| `/`、`/#product` | 无需登录的产品宣传页：价值、四组可切换界面示意、使用流程、应用入口 |
| `/#features`、`/#care` | 可直接打开宣传页的产品体验与使用流程区域 |
| `/#app` | 实际家庭账号与应用：小屋、照护、助手、成长、家庭 |
| `/#workbench` | 原演示登录、照护建议、审批、策略、回执与证据 |
| `/#home` | 原小屋；继续经过 App 的演示登录 |

沿用 hash 路由，后端无需添加 SPA fallback。宣传页不挂载业务组件，首次加载不请求 `/api/*`；不包含真实账号/宠物记录。小屋、任务、成长与对话预览明确标为产品示意。实际家庭应用仍从现有 API 获取记录，导航往返后恢复账号；原工作台与旧小屋共享 App 实例。

桌面家庭应用采用侧边导航，手机保留底部五入口。俯视房间与正面宠物造型保留。宣传页页脚、助手示意与应用内继续说明本地规则回答、Alexa 网页模拟、概念项圈、模拟设备及云端未验证。没有扩大实际功能或执行权限。
