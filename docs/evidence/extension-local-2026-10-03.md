## 运行

```powershell
# 在上述唯一仓库中；构建后启动
./scripts/dev-home.ps1
# App: http://127.0.0.1:8000/#app
# 保留的旧小屋: http://127.0.0.1:8000/#home

# 如果 8000 已占用，可使用独立预览库/端口
./scripts/dev-home.ps1 -Port 8807 -DatabasePath data/extension-preview.db
```

新 App 自行注册本地账号（密码至少 12 字符），创建家庭，或在另一个独立浏览器会话注册后接受邀请；账号之间不要共用同一浏览器 cookie 会话。
旧演示登录调用家庭 `/me` 后进入种子家庭；示例门禁沿用本地 README 配置，不是独立云账号。新家庭的 Mochi 只作档案，不能获得种子设备执行权。
浏览器复验可在进程中设置 `PAWTWIN_E2E_PORT=8806`；测试浏览器路径通过 `PAWTWIN_BROWSER_EXECUTABLE` 指定，不能把本机绝对路径写进共享配置。
