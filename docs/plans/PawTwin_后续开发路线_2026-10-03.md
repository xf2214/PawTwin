## 5. 风险与前置裁定

1. **契约膨胀**：新实体（User/Household/Membership/Invitation/Measurement/Observation/Report/PetContext…）会把 OpenAPI 推远超 28 路径；`EventIn.pet_id`/`StateView.pet_id` 的 `Literal["mochi"]` 与 `domain.schema.json` 六输入模型不变式须按附加计划 §10「**列消费者 + 兼容方案**」处理，**不得直接放宽 `test_contracts.py` 的 `==` 断言**。生成契约继续从 Python 源模型导出、禁止手改 JSON。
2. **`actor_id` 信任重构**：波及 `home_api` 所有写端点（`tasks/{id}/action`、`notes`、`diary`）+ `test_pet_home`；须服务端注入登录身份并补**越权负向测试**（伪造 `actor_id` 被拒/忽略）。
3. **迁移风险**：HomeStore 单 JSON 文档按 `owner` 键 → `household/pet/user` 归属；必须在 `data/pet-home.db` **副本**上幂等迁移 + 计数/关联核对 + 失败恢复，**禁止清库换绿**（QODER_HANDOFF）；旧 Mochi/配额明确映射到家庭与宠物，不同账号不得各复制一份额度控制同一设备。
4. **云阻断**：EXT-10 与任何「真实 AWS/Alexa」宣称顺延；命名门禁维持「本地验证候选（非参赛版）」，凭据就绪后按 [day5-cloud-blocked](../evidence/day5-cloud-blocked.md) 解锁前提逐项升格。
5. **容量**：EXT-00~12 远超单日；按 G0–G5 窗口推进，串行认领有限工作包，**不一次认领前端+身份+模型+部署**（附加计划 §11）。
6. **并发/所有权**（AGENTS）：EXT-01~06 后端**串行**（共享 `models`/`config`/`repository`/`api`）；EXT-07 前端可与后端并行，但 `api.ts` 串行协调；`models.py`/`contracts/`/`main.py`/`STATUS`/`TASKBOARD` 由 Coordinator 独占；**Reviewer 不得由作者充当**。
