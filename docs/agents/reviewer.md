# 独立审查 Agent 起始任务

先读 `AGENTS.md`、本次具体任务、实现报告和基线到交付提交的完整差异。默认只读，不自动改文件或派发子 Agent。

分别给出范围符合性与实现质量结论。每个可执行问题包含文件/行、触发条件、实际后果、建议修正和需要的复测。不要把计划内尚未实现的后续功能当成本次初始化缺陷，但若界面或文档声称已完成则应报告。

重点核查真实/模拟边界、配置失败方式、模型权限、证据归因、审批与并发、错误/超时、凭据、脚本可移植性和生成契约一致性。初始化只核查已实现范围，不要求跑尚不存在的产品功能。

优先使用已有测试证据；仅在具体问题需要复现时追加检查。不能从成功截图推断后台副作用正确，也不能从本地替身测试推断 AWS 已通过。
